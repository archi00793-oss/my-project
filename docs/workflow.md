# Как мы работаем вдвоём

Эмиль работает с Claude, друг — с Codex. Общее место — этот репозиторий.

## Один раз: подготовка компьютера

1. Установить Git: `winget install Git.Git`
2. Установить Node.js: `winget install OpenJS.NodeJS.LTS`
3. Скачать проект и установить зависимости:
   ```
   git clone https://github.com/archi00793-oss/my-project.git
   cd my-project
   npm install
   ```

## Каждая задача

1. Обновиться: `git checkout main` и `git pull`
2. Создать ветку: `git checkout -b codex/название-задачи` (или `claude/...`)
3. Попросить своего ИИ сделать задачу. Он работает по правилам из `AGENTS.md`.
4. Посмотреть результат: `npm run studio`
5. Сохранить и отправить:
   ```
   git add .
   git commit -m "Что сделано"
   git push -u origin codex/название-задачи
   ```
6. На GitHub открыть pull request (кнопка «Compare & pull request»), второй смотрит и
   нажимает «Merge».

Попросить ИИ сделать шаги 1, 2 и 5 тоже можно — он умеет работать с git.

## Кто за что отвечает (договорённость, можно менять)

| Область | Кто |
|---|---|
| Персонажи, фоны, сценарии серий | Эмиль + Claude |
| Анимационный «движок»: позы, переходы, липсинк, эффекты | друг + Codex |
| Общие компоненты (`Hero`, `Captions`, `video.ts`) | меняем через PR с пометкой |

## Если что-то сломалось

- `git status` — что изменено
- Конфликт при `git pull` — попросить своего ИИ: «разреши конфликт слияния»
- Ничего не рендерится — `npm install`, потом снова `npm run studio`
