# Локации серии 1 «Кассета»

Фоны находятся в `src/scenes/`. Это декорации для сборки по
`episodes/ep01-kasseta.md`, без персонажей, озвучки и монтажа серии.
Все фоны — SVG с плоскими заливками из `COLORS`, размер берётся из `VIDEO`.

## Apartment

```tsx
import { Apartment } from "../scenes/Apartment";

<Apartment />
<Apartment view="sink" />
<Apartment view="tv" tvContent={<Ded width={330} />} tvNoise={0.35} />
```

`view`: `wide` (по умолчанию, общий), `sink` (у раковины), `tv` (у телевизора).
Это три окна одной декорации: кухня слева, кровать в центре у тумбы,
телевизор справа, самокат в левом углу, антресоль сверху. За окном ночь.
Телевизор и самокат используют готовые `Tv` и `Scooter` из `src/props`.
`tvContent` передаётся внутрь экрана `Tv`, `tvNoise` — сила его помех 0..1.
Без содержимого экран чёрный, без помех.

Открытая ниша антресоли и полка тумбы пустые: коробки, видик и кассеты
добавляются в сценах по сценарию. Появление видика не зашито в фон.
Кровать намеренно остаётся видна рядом с тумбой на общем плане.

Для размещения персонажей и подвижного реквизита в укрупнениях экспортирован
`APARTMENT_VIEWS`. Если предмет задан в координатах общего плана `(x, y)`,
его экранные координаты и масштаб рассчитываются так:

```tsx
const camera = APARTMENT_VIEWS[view];
const scale = VIDEO.width / camera.width;
const left = (x - camera.x) * scale;
const top = (y - camera.y) * scale;
```

Ориентиры общего плана: ниша антресоли x=314..525, y=250..449;
раковина — центр (225, 1154); ТВ x=650, y=882, ширина 380;
пустая полка тумбы x=682..1003, y=1197..1293.
Интерфейс и субтитры размещать поверх сцены без преобразования координат.

## Doorway

`<Doorway />` или `<Doorway open />` — вид из квартиры на пустую площадку
с лестницей. `<Doorway open={false} />` — закрытая дверь перед звонком.
Состояние задаёт сцена, собственной анимации открывания нет.
Порог находится на y=1515..1558; место для коробки — по центру проёма,
примерно x=470..650. Коробку рисовать поверх фона так, чтобы её низ
оставался не ниже y=1650. В фоне нет людей, коробок и сюжетных подсказок.

## BlackCard

`<BlackCard />` — чистый чёрный фон для крупного плана кассеты или телефона.
`<BlackCard title="ЛЁХИНО" />` — финальный титр по центру безопасной зоны.
`children` — дополнительный React-контент поверх фона; для реквизита задавать
абсолютное позиционирование. Текст титра использует проектный Oswald.
