# Персонажи и предметы серии 1

Лист ассетов: композиция `Ep01-Assets` в `src/episodes/Ep01Assets.tsx`.
Это проверка внешности и интерфейса компонентов, а не монтаж серии.
Концепция и сценарий — `docs/series-bible.md` и `episodes/ep01-kasseta.md`.

## Персонажи

`Lyokha` из `src/characters/Lyokha` — худой парень в кепке козырьком назад,
мятом худи и жёлтой курьерской куртке. `jacket={false}` снимает куртку вместе
с её рукавами. `holdingPhone={false}` освобождает правую руку.

`Ded` из `src/characters/Ded` — Михалыч по пояс: седые волосы, короткая борода,
морщины, тельняшка. По умолчанию `expression="sly"`: хитрый прищур.
Его можно передать внутрь `<Tv>…</Tv>` без изменения самого персонажа.

Оба персонажа собраны из тела, рук, головы и общего лица. Параметры:

| Prop | Значение |
| --- | --- |
| `expression` | `neutral`, `happy`, `sad`, `surprised`, `angry`, `confused`, `sly`, `serious` |
| `mouthOpen` | 0..1, открытость рта; подходит для липсинка |
| `eyesOpen` | 0..1, открытость глаз; у деда дополнительно применяется прищур эмоции |
| `lookX` | -1..1, направление взгляда |
| `armLeft`, `armRight` | Подъём рук наружу, градусы; стороны указаны относительно экрана |
| `bendLeft`, `bendRight` | Только `Lyokha`: сгиб локтей внутрь, градусы; 0 сохраняет прежнюю геометрию |
| `phoneContent`, `phoneWidth` | Только `Lyokha`: содержимое экрана и ширина телефона в координатах персонажа. Ширина по умолчанию 66 сохраняет прежний вид; укрупнение растёт вверх от ладони |
| `headTilt` | Наклон головы, градусы |
| `bob` | Смещение верхней части тела по вертикали, px |
| `width`, `style` | Масштаб и размещение |

Позы задаются в сцене через props. Моргание, дыхание и липсинк подключаются
помощниками из `src/animation/`; компоненты не задают собственный тайминг.
Для поднятых рук нужно оставить место вокруг SVG.

## Предметы

Все экспортируются из `src/props`, масштабируются через `width`, принимают SVG-props
(`x`, `y`, `style` и другие). Высота рассчитывается автоматически.

| Компонент | Дополнительные props |
| --- | --- |
| `VhsTape` | `label`: текст наклейки с переносом по словам |
| `TapeBox` | `labels`: подписи вложенных кассет; по умолчанию пять подписей из сценария. `open={false}`: закрытая посылка без видимых кассет; по умолчанию открыта |
| `Vcr` | Старый видеомагнитофон |
| `Tv` | `children`: любой React-контент экрана; `noise`: сила помех 0..1 |
| `Phone` | `children`: любой React-контент экрана |
| `Doshirak` | `note`: необязательная запись на упаковке |
| `Scooter` | Самокат |

Экраны телевизора и телефона обрезают содержимое по скруглённому окну через
`foreignObject`. Содержимое занимает локальное окно 342×246 и 140×312 соответственно.
Помехи ТВ зависят от локального кадра и `random(seed)` из Remotion; повторный
рендер того же кадра даёт те же помехи. При `noise={0}` слой помех отсутствует.

В первой серии подписи кассет не раскрывают землю, стройку и условие о посёлке.
Адрес не придуман: `Doshirak` по умолчанию без записи.

## Проверка

```powershell
npm run typecheck
npx remotion still src/index.ts Ep01-Assets out/ep01-assets.png --frame=60
```

Размер и FPS берутся из `VIDEO`, длительность листа — из `sec(4)`.
Все значимые детали листа находятся между y=160 и y=1650.
