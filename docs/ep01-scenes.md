# Первые три сцены «Кассеты»

`Ep01-Kasseta` пока содержит только 0:00–0:18 сценария
`episodes/ep01-kasseta.md`. Последующие сцены не заменены заглушками.
Каждая сцена находится в собственном файле `src/episodes/ep01/SceneNN.tsx`
и зарегистрирована отдельно в папке `Ep01-Scenes` в Studio.

| Компонент / ID | Длительность | Содержание |
| --- | --- | --- |
| `Scene01` / `Ep01-Scene01` | `sec(4)` | Кассета на чёрном фоне, медленный наезд; акцент «похорон деда» |
| `Scene02` / `Ep01-Scene02` | `sec(6)` | Ночная однушка, еда над раковиной, самокат; акценты «Лёха», «четыреста рублей» |
| `Scene03` / `Ep01-Scene03` | `sec(8)` | Звонок, пустая площадка и закрытая коробка, перенос, распаковка, четыре подписи, первая кассета и реплика Лёхи |

Тайминг сцены 3 локальный: дверь открывается в 0,7 с; перенос коробки —
1,7–2,7 с; распаковка в квартире — 2,7–3,4 с; крупные планы четырёх
подписей по 0,6 с — 3,4–5,8 с; первая кассета и реакция — 5,8–8 с.
Подписи показаны отдельными вставками, чтобы их можно было прочитать.

Сборка использует готовый `Transitions` с прямыми склейками, без добавочных
эффектов и изменения длительности. `Camera` не масштабирует субтитры.
Текст реплик из сценария разбит на короткие субтитры; акцентные сочетания
связаны неразрывным пробелом. Озвучки пока нет, рот Лёхи в сцене 3
анимирован по интервалам его реплики, а не по голосу рассказчика.

## Минимальные дополнения к ассетам

- `Lyokha`: `bendLeft` и `bendRight` для еды и удерживания реквизита.
  При нулевом сгибе сохраняется прежняя геометрия рук.
- `TapeBox`: `open={false}` скрывает кассеты и закрывает клапаны посылки.
  По умолчанию коробка открыта, как прежде.
- Собственный двухтональный звонок `public/sfx/ep01-doorbell.wav` подключён
  через `Sfx`. Перегенерация: `node scripts/generate-ep01-doorbell.mjs`.

`Hero`, `Captions`, `Room`, `Camera`, `Transitions`, `Sfx`, `Apartment`,
`Doorway`, `BlackCard`, палитра и правила проекта не изменены.

## Проверка

```powershell
npm run typecheck
npm run test:engine
node scripts/check-ep01-scenes.mjs
```

| Сцена | Глобальные кадры | Файлы в `out/` |
| --- | --- | --- |
| 1 | 30, 105 | `ep01-scene01-a.png`, `ep01-scene01-b.png` |
| 2 | 135, 270 | `ep01-scene02-a.png`, `ep01-scene02-b.png` |
| 3 | 336, 510 | `ep01-scene03-a.png`, `ep01-scene03-b.png` |

Полный рендер на этом этапе не выполняется. Для предпросмотра:
`npm run studio -- --no-open`, затем выбрать `Ep01-Kasseta`.

(PR #2) и локации (PR #3), затем перенаправить PR сцен в `main`.
