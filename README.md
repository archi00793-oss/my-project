# Мультсериал: вертикальные ролики из кода

Персонаж, комната, субтитры и счётчик дней собираются в коде на [Remotion](https://www.remotion.dev)
и рендерятся в MP4 1080×1920. Озвучку и музыку добавляем сами.

## Быстрый старт (Windows, PowerShell / Warp)

```
git clone https://github.com/archi00793-oss/my-project.git
cd my-project
npm install
npm run studio
```

`npm run studio` открывает в браузере редактор: там видно все серии, можно листать кадры
и смотреть ролик без рендера.

Отрендерить тестовый ролик в файл:

```
npx remotion render src/index.ts Ep00-Test out/ep00-test.mp4
```

Готовый файл появится в папке `out`.

## Что где лежит

- `AGENTS.md` — правила для ИИ (Codex и Claude работают по одним правилам)
- `docs/series-bible.md` — герой, мир и тон сериала
- `docs/workflow.md` — как работаем вдвоём
- `docs/engine.md` — как применять камеру, переходы, пословные субтитры, SRT и SFX
- `episodes/` — сценарии серий
- `src/` — код: персонажи, фоны, субтитры, серии

Подробности по структуре и правилам — в `AGENTS.md`.

`Ep00-Test` показывает четыре сцены с камерой, тремя переходами, обоими режимами субтитров
и звуками. Включите звук в Studio. Проверки движка: `npm run test:engine` (Node.js 22.18+).
