# Правила проекта для ИИ-агентов (Codex и Claude)

Этот файл — единственный источник правил. Codex читает его напрямую, Claude — через CLAUDE.md.
Если меняешь правила, меняй их здесь и сообщи об этом в описании pull request.

## Что за проект

Мультяшный сериал вертикальных роликов (Reels / Shorts / TikTok) про одного героя,
у которого есть цель и срок. Ролики рендерятся из кода на Remotion (React + TypeScript).
Озвучку и музыку люди добавляют сами (или кладут файл в `public/audio/` для липсинка).

Над проектом работают два человека, у каждого свой ИИ-агент:
- **Эмиль** работает с Claude;
- **его друг** работает с Codex.

Агенты не общаются напрямую. Всё, что нужно знать другому, записывай в репозиторий:
код, этот файл, `docs/`, описание pull request.

## Структура

```
AGENTS.md              — правила (этот файл)
CLAUDE.md              — ссылка на AGENTS.md для Claude
docs/series-bible.md   — библия сериала: герой, мир, тон, сквозные элементы
docs/workflow.md       — как люди работают вдвоём (git, ветки, рендер)
episodes/              — сценарии серий в Markdown (_template.md — шаблон)
public/audio/          — озвучка и музыка (mp3/wav)
public/fonts/          — шрифты (Oswald 700, кириллица + латиница)
public/images/         — растровые картинки, если понадобятся
src/config/video.ts    — размер кадра, FPS, палитра, шрифты, sec()
src/config/fonts.ts    — загрузка шрифтов
src/animation/         — анимационные помощники (моргание, дыхание, рот, пружины)
src/characters/<Имя>/  — персонажи, собранные из частей, управляются через props
src/scenes/            — фоны и локации
src/components/        — элементы интерфейса: субтитры, счётчик дней и т. п.
src/episodes/EpNN*.tsx — серии; каждая регистрируется в src/Root.tsx
out/                   — готовые рендеры (в git не попадают)
```

## Технические правила

- Кадр **1080×1920, 30 fps**. Не хардкодь числа: бери из `VIDEO` и `sec()` в `src/config/video.ts`.
- Все цвета — из `COLORS`. Новый цвет сначала добавь в палитру.
- Анимация зависит только от номера кадра (`useCurrentFrame`). `Math.random()` запрещён —
  если нужна случайность, используй `random(seed)` из `remotion`.
- Персонажи и фоны — плоский вектор (SVG внутри React-компонентов). Без градиентов,
  без обводок, мягкие скруглённые формы.
- Персонаж не перерисовывается в сериях. Поза, эмоция, рот, глаза, руки задаются props.
  Нужна новая поза/эмоция — добавь её в компонент персонажа, а не копируй SVG в серию.
- Субтитры — компонент `Captions`. Реплики пишутся обычным регистром, компонент сам
  делает КАПС. Неразрывный пробел ` ` — чтобы слова не разрывались между строками.
- Важные элементы держи в «безопасной зоне»: не выше 160 px сверху и не ниже 1650 px —
  там интерфейс соцсетей.
- Комментарии в коде и документация — на русском.

## Проверка перед коммитом

```
npm run typecheck
npx remotion still src/index.ts <ID-композиции> out/check.png --frame=60
```

Открой `out/check.png` и убедись, что кадр выглядит как задумано. Для финальной проверки —
полный рендер: `npx remotion render src/index.ts <ID> out/<имя>.mp4`.

## Git

- В `main` напрямую не пушить. Каждая задача — отдельная ветка:
  `claude/<коротко-о-задаче>` или `codex/<коротко-о-задаче>`.
- Изменения вливаются через pull request. В описании PR: что сделано, что проверено,
  какие правила/компоненты изменились.
- Перед началом работы: `git pull` из `main`, чтобы не работать со старой версией.
- Не переписывай чужие компоненты молча. Если нужно изменить общий компонент
  (`Hero`, `Captions`, `Room`, `video.ts`), напиши об этом в PR отдельной строкой.

## Как добавить серию

1. Сценарий: скопируй `episodes/_template.md` → `episodes/epNN-название.md`, заполни.
2. Код: скопируй `src/episodes/Ep00Test.tsx` → `src/episodes/EpNN<Название>.tsx`.
3. Зарегистрируй серию в `src/Root.tsx` (id в формате `EpNN-Название`).
4. Если есть озвучка: положи в `public/audio/epNN.mp3`, подключи `<Audio>` из `remotion`
   и `useMouthFromAudio("audio/epNN.mp3")` для движения рта.
5. Проверь кадры, отрендерь, открой PR.
